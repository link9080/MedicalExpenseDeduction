# 医療費控除スキャナー (医療費控除DX)

スマートフォンでレシートや領収書を撮影・選択するだけで、AI（Gemini API）が医療費控除に対象となる商品・金額を自動抽出し、Google スプレッドシートへ高速に記録・保存するWebアプリケーションです。

1つのレシート内に複数の医療費控除対象商品（医薬品など）が含まれている場合でも、一括して自動抽出し、個別にデータ登録が可能です。

## 主な機能と特徴

- **スマートなカメラ・アルバム連携**: 
  - スマホ端末から「カメラ起動」と「アルバム選択」をユーザーが自由に選択可能。
  - 固有のフォトピッカー仕様（カメラが選択肢から消える現象）を回避する拡張子ダミーバリデーションを実装。
- **AIマルチアイテム抽出**: 
  - `Gemini` を採用し、レシート画像から「購入場所」「購入日」「合計金額」に加え、**医療費控除に関連する商品（複数可）とその金額**を構造化JSONとして一括抽出。
- **不正ファイルブロック**: JavaScript側でMIMEタイプを検証し、PDFやZipなどの画像以外のファイルを送信前にフロントで検知・遮断。
- **フォールバック機能**: AIサーバーの混雑時（503エラー等）や解析失敗時には、シームレスに手動入力フォームへ切り替え可能。
- **データ管理（CRUD）**: 過去の登録履歴の閲覧、スプレッドシート上のデータの直接編集・削除に対応。

## システム構成
```
[スマートフォン / ブラウザ]
│ (Base64化した画像 + 認証パスワード)
▼
[Google Apps Script (GAS)] ──(認証確認)
│
├──► [Gemini API (gemini-1.5-flash)] ※レシート解析・JSON整形
│
└──► [Google スプレッドシート] ※データの蓄積・編集・削除
```

## 開発環境の起動・ローカルデバッグ手順

WebフロントエンドをローカルPCで起動し、同じWi-Fi（ローカルネットワーク）内にある実機スマートフォンからカメラ挙動をテストするための手順です。

### 1. Windows環境での注意点

**WSL環境で動かす場合**

*WSLのIPを調べる*
```
hostname -I
```

*管理者権限でコマンドプロンプトで以下コマンドを実行*
```
netsh interface portproxy add v4tov4 listenport=8000 listenaddress=0.0.0.0 connectport=8000 connectaddress=[上記WSLのIPアドレス]
```

### 2. ファイアウォールの設定
Windows Defender等のファイアウォールで、使用するポート（例: `8000`）の **TCP受信規則（接続を許可）** を追加しておきます。
※Wi-Fiのネットワークプロファイルが「パブリック」になっていると通信が遮断されるため、必ず **「プライベート」** に変更してください。

### 3. ローカルサーバーの起動
HTMLファイルが存在するディレクトリで、以下のコマンドを実行し、すべてのネットワークインターフェースからの接続を許可して起動します。

```bash
# WindowsのコマンドプロンプトまたはPowerShellで実行
python -m http.server 8000 --bind 0.0.0.0
```
### 4. スマートフォンからのアクセス
PCのローカルIPアドレスを調べます（ipconfig コマンドで IPv4 アドレス を確認。例: 192.168.1.15）。



PCと完全に同じSSID（Wi-Fi）にスマホを接続します（2.4GHz / 5GHzの混在に注意。有線PCと無線スマホの場合でも、ルーターのセパレータ機能がオフであれば通信可能です）。

スマホのブラウザから以下のアドレスを入力してアクセスします。
```
http://[PCのIPアドレス]:8000
```
※ルーターのセキュリティ等で通信が通らない場合の最終手段として、スマホの「テザリング」にPCをWi-Fi接続させる方法が確実です。

## 5.設置・設定のポイント（GAS / Gemini API）
### 1. Gemini APIのプラン確認
APIリクエスト時に 429 RESOURCE_EXHAUSTED (Your prepayment credits are depleted...) エラーが発生する場合、Google AI Studioのプロジェクトが「有料プラン（Prepaid）」に移行した状態でデポジット残高が空になっています。

対応策: [Google AI Studio] の Billing セクションからクレジットをチャージするか、請求アカウントが紐づいていない純粋な無料枠（Free Tier）のプロジェクトでAPIキーを再発行し、GASのスクリプトプロパティを差し替えてください。

### 2. GASプロンプトの期待するレスポンススキーマ
GASからGemini APIへは、以下の構造化JSONで返すようプロンプトが最適化されています。
```
{
  "isValid": true,
  "invalidReason": "",
  "store": "店舗名",
  "date": "YYYY/MM/DD",
  "totalPrice": 0,
  "items": [
    {
      "name": "医薬品名1",
      "price": 1280
    },
    {
      "name": "医薬品名2",
      "price": 980
    }
  ]
}
```
### 6.構成ファイル
**index.html :** Tailwind CSSを使用したレスポンシブWebUI。

**js/app.js :** 画像リサイズ、フロントバリデーション、GASとの非同期通信、複数商品の動的レンダリングロジック。

**css/index.css :** アプリケーションのカスタムスタイル。
